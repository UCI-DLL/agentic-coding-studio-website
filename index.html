The learning cycle

Young people direct the process, not just the prompt.

Creation becomes a cycle of intention, review, evidence, and revision.

  1. Choose a goal
  2. Make a clear request
  3. Review the agent’s plan
  4. Build or revise
  5. Run and test
  6. Give feedback
  7. Reflect

What learners practice

More than getting code to run.

01

Learner-directed coding

Learners set meaningful goals, communicate intent, and decide what the agent should do next.

02

Computational agency

They use computational tools intentionally, critically, and creatively—and evaluate the results.

03

Learning through creation

Games, stories, simulations, and apps give ideas a form that can be shared, tested, and improved.

Why now

As code production changes, computational thinking still matters.

When AI agents take on more mechanical production, people need to be better at specifying intent, decomposing problems, setting constraints, evaluating outputs, testing behavior, and revising systems toward meaningful goals.

Agentic Coding Studio does not treat AI as an answer machine or a replacement for thinking. It studies how learners can work with AI while retaining responsibility for what they make and why.
