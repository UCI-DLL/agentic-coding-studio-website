The core difference

The agent participates in a visible learning loop.

Learners can communicate intent in natural language while retaining access to visual coding blocks. The design creates opportunities to examine proposed work, approve a direction, run the project, identify problems, and ask for focused changes.

The platform is under research and development. The design directions below include prototype components and planned supports; they should not be read as a list of fully released features.

Educational design

Supports for thoughtful participation.

Each element is intended to keep the learner engaged in consequential decisions rather than optimizing only for speed.

01
Foundation

Block-based computational creation

The Studio builds on a visual, block-based environment in which learners can create games, interactive stories, simulations, apps, and other computational artifacts. Blocks keep computational structures available for inspection and modification.

02
Developing design

Natural-language coding agent

The agent is intended to clarify underspecified requests, propose manageable plans, summarize changes, and remain interruptible. Learners review and guide its work instead of treating generated code as a finished answer.

03
Project component

Prompt Clinic

Prompt Clinic supports learners in improving the clarity and specificity of requests. It is conceived both as feedback for learners and as a way for researchers to study how prompting develops over time.

04
Learning design

Milestones, not rigid recipes

Stable anchors—such as project goals, feature milestones, objects, expected behaviors, and success checks—can support varied prompts and implementation paths without prescribing every step.

05
Design goal

Review, approval, testing, and revision

The environment is being designed to make consequential moments visible: reviewing a plan, approving action, inspecting changes, testing behavior, giving feedback, and deciding what to revise next.

06
Planned support

Pedagogical supports and constraints

Rather than behaving like an unrestricted production tool, the learning environment can provide scaffolds that encourage explanation, reflection, manageable steps, and educator facilitation.

Two connected purposes

Designed for learning—and for studying learning.

The same environment that supports youth creation can help researchers examine interaction over time.

With appropriate research procedures, project artifacts, prompting and revision patterns, observations, and other evidence can inform iterative improvement. The purpose is not to monitor for its own sake, but to understand how platform and activity design shape learner participation.
